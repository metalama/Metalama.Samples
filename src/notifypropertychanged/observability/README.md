# Example: using the ready-made Observable aspect

[!metalama-project-buttons .]

`Metalama.Patterns.Observability` is an open-source package that
implements <xref:System.ComponentModel.INotifyPropertyChanged> for you. This example applies
its <xref:Metalama.Patterns.Observability.ObservableAttribute?text=[Observable]> aspect to a type that has a computed
property. This is the approach to use in production code. The other examples of this section build a comparable aspect
from scratch for didactic purposes.

Two steps are required to use the aspect:

1. Add a reference to the `Metalama.Patterns.Observability` package.
2. Add the `[Observable]` attribute to the type. The aspect is inherited, so a derived class does not need the attribute
   when a base class already has it.

Here is the transformation. The code generated by Metalama is displayed in green.

## What the aspect generates

The `Velocity` property is computed from `DX` and `DY`. The aspect discovers this dependency by analyzing the type, so
the setters of `DX` and `DY` raise a notification for `Velocity` in addition to the notification for the property being
set. This is the case that the custom aspect of <xref:sample-notifypropertychanged-custom> cannot handle.

The generated setters also compare the new value with the current one, and raise no notification when the value is
unchanged. Finally, the aspect converts the automatic properties into field-backed properties, adds
the <xref:System.ComponentModel.INotifyPropertyChanged> interface, and adds a `virtual` `OnPropertyChanged` method that
raises the event.

Running the program gives the following output. The third line shows the notification for the computed property, raised
by the setter of `DX`.

```text
X has changed
Y has changed
Velocity has changed
DX has changed
```

## Going further

The aspect supports more constructs than this example shows, in particular properties that depend on the properties of
child objects, and methods that are known to return the same value for the same arguments. When the aspect encounters a
dependency it cannot analyze, it reports a warning in the `LAMA51xx` range instead of generating incorrect code. The
`[NotObservable]`, `[Constant]` and `[SuppressObservabilityWarnings]` attributes, and the `ConfigureObservability`
fabric method, let you address these warnings. For the complete reference, see <xref:observability>.
