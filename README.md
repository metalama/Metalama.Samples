# Metalama.Samples

Annotated samples for [Metalama](https://github.com/metalama/Metalama), the open-source patterns & architecture toolkit for C#.

Each sample is a working project that shows a pattern implemented as an aspect, with the source code and the generated code side by side. Read them online at [Metalama Examples](https://doc.postsharp.net/metalama/examples), where they are rendered with the transformed code, or open any directory in this repository to build and step through it yourself.

The samples cover design patterns (Builder, Memento, Singleton, Factory), object services (cloning, `ToString`, comparison), UI patterns (`INotifyPropertyChanged`, change tracking, commands), exception handling and retry, logging, caching, and code validation.
